Laboratory Task 5 — PyTorch Basics

Name: Emmanuel R. Sevilla
DS4A

This notebook answers Laboratory Task 5 from 02_PyTorch Basics.ipynb. Each step of the task has its own cell so the results are easy to check.

1. Standard imports¶

import numpy as np
import torch

print("NumPy  :", np.__version__)
print("PyTorch:", torch.__version__)
NumPy  : 2.1.3
PyTorch: 2.11.0+cpu

2. Create set_seed(seed: int)¶

The function sets the random seed for NumPy and PyTorch. It returns nothing.

def set_seed(seed: int) -> None:
    np.random.seed(seed)
    torch.manual_seed(seed)

3. Create the NumPy array arr¶

Six random integers from 0 (inclusive) to 5 (exclusive), using seed 42. The dtype is int32 so Step 5 can change it to int64.

set_seed(42)
arr = np.random.randint(0, 5, size=6).astype("int32")

print("arr   :", arr)
print("dtype :", arr.dtype)
arr   : [3 4 2 4 4 1]
dtype : int32

4. Make tensor x from arr¶

x = torch.from_numpy(arr)

print(x)
print("dtype:", x.dtype)
tensor([3, 4, 2, 4, 4, 1], dtype=torch.int32)
dtype: torch.int32

5. Change x from int32 to int64¶

x = x.long()

print(x)
print("dtype:", x.dtype)
tensor([3, 4, 2, 4, 4, 1])
dtype: torch.int64

6. Reshape x to 3 × 2¶

x = x.reshape(3, 2)

print(x)
print("shape:", x.shape)
tensor([[3, 4],
        [2, 4],
        [4, 1]])
shape: torch.Size([3, 2])

7. Get the right-hand column of x¶

right_col = x[:, 1]
print(right_col)
tensor([4, 4, 1])

8. Square the values of x without changing x¶

x ** 2 makes a new tensor, so x stays the same.

squared = x ** 2

print("Squared:")
print(squared)
print("\nx is still:")
print(x)
Squared:
tensor([[ 9, 16],
        [ 4, 16],
        [16,  1]])

x is still:
tensor([[3, 4],
        [2, 4],
        [4, 1]])

9. Create tensor y¶

x is 3 × 2, so y needs 2 rows to be multiplied with x. To keep 6 elements like x, y is 2 × 3.

torch.manual_seed(42)
y = torch.randint(0, 5, (2, 3))

print(y)
print("shape   :", y.shape)
print("elements:", y.numel())
tensor([[2, 2, 1],
        [4, 1, 0]])
shape   : torch.Size([2, 3])
elements: 6

10. Matrix product of x and y¶

A 3 × 2 matrix times a 2 × 3 matrix gives a 3 × 3 matrix.

product = x @ y

print(product)
print("shape:", product.shape)
tensor([[22, 10,  3],
        [20,  8,  2],
        [12,  9,  4]])
shape: torch.Size([3, 3])

Summary¶

All 10 steps are done: imports, set_seed(), the seeded NumPy array, conversion to a tensor, int64 change, 3 × 2 reshape, right column, squared values, a 2 × 3 tensor y, and the matrix product.
